#  Flappy Bird 🐦

A simple Flappy Bird game built using Java Swing, focusing on Object-Oriented Programming concepts.

## 🎮 Controls
* **[ S ]** - Start the game (from the main menu).
* **[ UP ARROW ]** - Jump / Fly upwards.
* **[ R ]** - Restart the game after a Game Over.

## 🛠️ How to Run
1. Open the project in any Java IDE (e.g., VS Code, IntelliJ).
2. Ensure that `GameOverSound.wav` and `Image.png` are placed inside the `src/game/` folder.
3. Run **`MainGame.java`** to start the game.
